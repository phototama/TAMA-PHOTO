📎 Pengiriman File Dokumen

Setelah mengirim detail pesanan melalui WhatsApp, Anda dapat mengirimkan file dokumen kepada admin melalui percakapan WhatsApp yang sama. Pastikan file yang dikirim sudah benar dan siap untuk dicetak.

💳 Informasi Pembayaran

Admin akan memeriksa detail pesanan dan mengonfirmasi total harga terlebih dahulu. Setelah harga disepakati, pelanggan melakukan pembayaran. Pesanan mulai diproses setelah pembayaran diterima dan diverifikasi.

📍 Pengambilan Hasil Cetakan

Setelah proses pencetakan selesai, pelanggan dapat mengambil hasil cetakan langsung di lokasi TAMA PHOTO. Saat ini kami belum menyediakan layanan pengantaran atau delivery.
