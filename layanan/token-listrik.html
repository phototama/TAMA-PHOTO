💳 Informasi Pemesanan dan Pembayaran
  • Pastikan ID pelanggan atau nomor meter sudah benar sebelum mengirim pesanan.
  • Admin akan memeriksa data pelanggan, ketersediaan token, dan total harga beserta biaya layanan.
  • Pembayaran dilakukan setelah pelanggan menyetujui total biaya.
  • Token hanya diproses setelah pembayaran diterima dan diverifikasi admin.
  • Setelah transaksi berhasil, kode token akan diberikan kepada pelanggan.

Periksa kembali ID pelanggan atau nomor meter sebelum melakukan pembayaran. Kesalahan data dapat menyebabkan token terkirim ke pelanggan yang tidak sesuai.
